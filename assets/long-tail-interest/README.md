- 同名 MP4：将对应词云背景与透明轮播合成的 H.264 兼容版本（960 × 720），供 WebKit 或 WebM 播放失败时使用。背景词云以 44% 不透明度呈现，与网页透明视频叠加效果一致。

- `*-cloud.png`：用户提供的两张词云，缩放至 1280 × 800，支持页面内放大。
